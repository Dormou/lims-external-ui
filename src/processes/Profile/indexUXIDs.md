## Описание ID элементов UI

Ниже представлен список ID элементов пользовательского интерфейса с краткими описаниями:

1.  `profile-menu-button`: Кнопка открытия меню профиля в шапке.
2.  `personal-cabinet-menu-item`: Элемент меню "Личный кабинет".
3.  `user-info-block`: Блок с информацией о пользователе.
4.  `reset-changes-button`: Кнопка "Сбросить изменения" в блоке информации.
5.  `save-changes-button`: Кнопка "Сохранить изменения" в блоке информации.
6.  `is-tech-contact-checkbox`: Чекбокс "Я являюсь контактным лицом по техническим вопросам".
7.  `tech-contact-firstName`: Поле ввода имени для контактного лица по тех. вопросам.
8.  `tech-contact-lastName`: Поле ввода фамилии для контактного лица по тех. вопросов.
9.  `is-head-checkbox`: Чекбокс "Я являюсь руководителем организации".
10. `head-firstName`: Поле ввода имени для руководителя организации.
11. `head-lastName`: Поле ввода фамилии для руководителя организации.
12. `change-password-button`: Кнопка "Изменить пароль".
13. `old-password-input`: Поле ввода старого пароля.
14. `new-password-input`: Поле ввода нового пароля.
15. `confirm-password-input`: Поле ввода подтверждения нового пароля.
16. `save-password-button`: Кнопка "Сохранить пароль" в форме смены пароля.
