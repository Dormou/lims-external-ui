# LIMS Frontend (React + Vite + TypeScript)

Внешний интерфейс LIMS.

## 🚀 Быстрый старт для разработки

### 1. Установка зависимостей
Убедитесь, что у вас установлена Node.js версии 20+. В корне папки фронтенда выполните:
```bash
npm install
```

### 2. Запуск в режиме разработки
Проект настроен на проксирование API-запросов к удаленному серверу через `vite.config.ts`.
```bash
npm run dev
```
После запуска интерфейс будет доступен по адресу: `http://localhost:5173`. 
Все запросы к `/api/*` будут автоматически перенаправляться на `http://lims.ntc-tech.ru`.
